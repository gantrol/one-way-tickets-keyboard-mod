# 《再再启程》键盘 Mod

不用再点工具箱，解放鼠标，避免腱鞘炎。

## 安装 / 卸载

从 [Releases 下载最新版本](https://github.com/gantrol/one-way-tickets-keyboard-mod/releases/latest)（一键安装器或完整压缩包）。

1. 关闭游戏，运行 `双击一键安装或卸载Mod.exe`。
2. 确认自动识别的游戏目录，点击「一键安装 / 更新 Mod」；找不到目录时可手动浏览。
3. 卸载时再次运行安装器，点击「一键卸载还原原版」。
