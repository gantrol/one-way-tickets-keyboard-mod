## 1. 双手人体工学分区与固定 5 槽架构

### 1.1 双手主行（`CapsLock` + `ASDFG` + `HJKL;`）设计理念
- **最频繁的操作放在双手主行（Home Row）**：
  - **左手主行 `Caps Lock` + `A S D F G`**：1~5 号固定武器槽主控（开火 / 挥砍 / 空仓自动装填），左手小指点按 `Caps Lock` 一键开启/关闭全武器 `[AUTO]` 自动托管（或 `Ctrl + A~G` 单槽切换）。
  - **右手主行 `H J K L ;`**：工具箱 5 大核心工具（扳手 / 灭火器 / 锯子 / 抹布吹风 / 唤醒），手指无需离开主行即可秒级抢修，配合大拇指 `Space` 全车智能抢修。
- **左手上排 `Q W E R T`**：与下方 `A S D F G` 垂直一一对齐，专职 **1~5 号槽定点抢修**（除障 + 修血）。
- **左手下排 `Z X C V`**：专职行车驾驶——**`Z` 刹车**、**`X` 灵能加速（冲刺）**、**`C` 熔炉风箱（鼓风/推车）**、**`V` 车轮槽保留键**。
- **右手上排 `Y U I O P [` + `]`/`'`**：专职 **1~6 号人物选择与派驻**（同时保留数字键 `1~6` 兼容），按 **`'` 或 `]`** 一键将角色按能力值自动分配到最优槽位。

### 1.2 为什么武器槽固定为 5 个（排除车轮槽）？
通过反编译游戏核心程序集 `World.dll`、`AutoCodes.dll` 及场景资源确认：
- 游戏内**所有载具（篷车）最多只有 5 个武器/设备槽位**，从左到右依次为：
  1. `slot_back`（1 号：后槽，对应武器 `A` / 抢修 `Q`）
  2. `slot_back_top`（2 号：后顶槽，对应武器 `S` / 抢修 `W`）
  3. `slot_top`（3 号：顶槽，对应武器 `D` / 抢修 `E`）
  4. `slot_front_top`（4 号：前顶槽，对应武器 `F` / 抢修 `R`）
  5. `slot_front`（5 号：前槽，对应武器 `G` / 抢修 `T`）
- 底层 `DeviceMgr.slots_device` 中的第 6 项是 **`device_slot_wheel`（左侧仪表盘的车轮槽）**，现已独立绑定到左手下排保留键 **`V`**，不再占用武器槽位。

## 2. 工具箱各升级阶段（Stage-Aware）与拎出/放回动画

### 2.1 工具拎出与放回动画（异常安全 `try-catch`）
- 每次按下 `H J K L ;`、`Q W E R T` 或 `Space` 触发工具时，`ToolAnimationController` 会自动读取原版 `PlayerToolMgrView` 与 `ToolLogic` 的贴图（`press_tool` / `pick_tool` / `normal_tool`），临时掀开工具箱盖（`box_sprites[1]`），播放**从右侧工具箱拎出工具 → 飞向目标槽位/角色执行动作（擦拭画圈、吹风横扫、拉锯、棘轮旋转、喷射、敲击）→ 飞回工具箱放好**的完整视觉动画。
- 所有动画步骤均包裹在独立的 `try { ... } catch { }` 异常保护块中：即使未来游戏版本更新更改了 UI 预制体结构导致动画无法提取，底层的修理/灭火/割藤/擦水/唤醒数值逻辑也 **100% 不受影响**。

### 2.2 各阶段自动适配表

| 快捷键 | 工具进化路线 | 各阶段自动适配行为 |
| :--- | :--- | :--- |
| **`Space`** | **全局智能抢修** | 按紧急优先级自动处理：唤醒昏迷角色 → 灭火 → 除酸 → 擦水/吹干 → 割表层藤蔓 → 踹醒沉睡设备 → 扳手修 0 血设备 → 车载维修包回血 |
| **`Q~T`** | **1~5 号槽定点抢修** | 对正下方 `A~G` 对应的固定槽位执行：除酸 → 灭火 → 割藤 → 擦水/吹干 → 踹醒 → 扳手/维修包修血 |
| **`H`** | **单向扳手 → 棘轮扳手 → 自动扳手 + 车载维修包** | 有 0 血损毁设备时按当前扳手阶段倍率抢修；无 0 血设备时自动触发**车载维修包（`Widget_Fix_Context`）**为受损设备或车体回血 |
| **`J`** | **灭火器（各阶段）** | 按当前灭火器等级速率扑灭着火设备 |
| **`K`** | **手锯 (`Lv0`) → 剪刀 (`Lv1`) → 电锯 (`Lv2`) → 圆锯 (`Lv3`)** | 自动识别藤蔓层级（`upper_vines.Count == 0`），永远从最外层藤蔓开始切除（**零顺序错误扣血惩罚**），切割速度随阶段倍增 |
| **`L`** | **抹布 (`Lv0`) → 大抹布 (`Lv1`) → 拖把 (`Lv2`) → 吹风筒 (`Lv3`)** | **前期（抹布/大抹布/拖把）**：免瞄准自动擦除单台设备上的水滴与强酸；<br>**后期（吹风筒 `Drier` `Lv3`）**：按下 `L` 直接触发**全车所有设备同步吹干**！ |
| **`;`** | **充气锤 (`Lv0`) → 惨叫鸡 (`Lv1`) → 闹钟 (`Lv2`) → 除颤仪 AED (`Lv3`)** | **前期**：每次敲醒 1 名昏迷角色（支持 `; + Y~[` 指定唤醒）；<br>**后期（除颤仪 `AED` `Lv3`）**：按下 `;` 直接**全车所有昏迷角色同步电击唤醒**！ |

## 3. 行车控制：刹车（`Z`）、灵能加速（`X`）、风箱（`C`）与车轮槽（`V`）

| 快捷键 | 功能名称 | 底层联动机制 |
| :--- | :--- | :--- |
| **`Z`（按住）** | **篷车刹车（Brake）** | 同步拉起驾驶台红色刹车拉杆（`CaravanLever2.lever_slider`）并将 `WorldContext.brake_lever_input` 设为 `1.0`；松开 `Z` 自动释放拉杆恢复行进 |
| **`X`（点按）** | **灵能加速（Psionic Boost）** | 独立触发右侧仪表盘的**灵能冲刺按钮（`SpeedChargeView.@do()`）**，与风箱完全解耦，避免误消耗灵能冲刺冷却或次数 |
| **`C`（按住/点按）** | **熔炉风箱（Bellows）** | 按住期间持续鼓动**熔炉风箱（`Widget_Blower_Context` / `BellowView`）**提速，松开停止鼓风；若篷车停滞则自动触发推车启动（`Widget_PushCar_Context`） |
| **`V`（点按）** | **车轮槽保留键** | 独立触发 `device_slot_wheel` 上的车轮主动技能（如 `JetWheel` 喷气加速、`BasicWheelUiView.Push_Car_btn` 推车） |

## 4. 人物调配（`Y U I O P [`）与一键智能自动分配（`'` / `]`）

- **手动选人与派驻**：
  - 按 **`Y U I O P [`**（或数字键 **`1 ~ 6`**）选中第 1~6 号角色 → 再按 **`A ~ G`**（或 **`Q ~ T`**）将其派驻到对应槽位（若已在槽位内，再次派驻可在主攻击位 / 装填位 / 搬运位 / 磨刀位之间切换）。
  - **双击角色键** 或按 **`Backspace` / `0`**：将该角色撤回休息区。
- **一键最优自动分配（`'` 或 `]`）**：
  - 读取每位角色的 `Character.GetAbility(device)` 与 `CanWork(device)` 能力矩阵，结合槽位紧急程度（损毁急需修理 > 主工位空缺 > 弹尽急需装填/搬运/磨刀 > 副工位空缺），采用全局贪心匹配将所有清醒角色一键派驻到最适合的岗位。
  - 若存在昏迷角色，按 `'` / `]` 还会自动顺带触发一次唤醒工具。
- **持续自动调配开关（`Ctrl + '` 或 `Ctrl + ]`）**：
  - 开启后每 0.5 秒自动巡检：当某台单人值守的远程武器打空弹药（或大剑钝化）时，自动将该角色临时移到**装填/搬运/磨刀副工位**，装填完毕后自动切回**主攻击工位**！

## 6. 工具箱上方反馈面板与自定义改键

- **按键响应位置（右侧工具箱正上方）**：
  - 遵循原版 UI 布局，按键反馈、工具箱快捷键提示、人物自动分配状态及 `[AUTO]` 托管状态统一锚定在**右侧工具箱图标正上方的深色留白区域**，绝不遮挡顶部路线进度条或左上角遗物栏。
- **自定义键位（`OneWayTickets.KeyboardMod.ini`）**：
  - 安装后在游戏根目录生成 `OneWayTickets.KeyboardMod.ini`，可用记事本修改任意按键或修理速率倍率，游戏中按 **`F10`** 热重载生效，按 **`F9`** 显隐界面提示。
- **从源码重新编译并打包单文件安装器（仅开发者需要）**：
  ```powershell
  dotnet build .\OneWayTickets.KeyboardMod.csproj -c Release
  ```
  编译完成后会自动更新 `dist\OneWayTickets.KeyboardMod.dll` 并重新生成单文件绿色安装器 `双击一键安装或卸载Mod.exe`（完全不依赖 `.ps1` 或 `.bat` 脚本）。
