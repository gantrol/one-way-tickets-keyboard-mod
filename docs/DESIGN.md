## 1. 为什么武器槽与抢修槽固定为 5 个键位（`Q W E R T` / `A S D F G`）？

通过反编译游戏核心程序集 `World.dll`、`AutoCodes.dll` 及场景资源确认：
- 游戏内**所有载具（篷车）最多只有 5 个武器/设备槽位**，从左到右依次为：
  1. `slot_back`（1 号：后槽，对应 `Q` / `A`）
  2. `slot_back_top`（2 号：后顶槽，对应 `W` / `S`）
  3. `slot_top`（3 号：顶槽，对应 `E` / `D`）
  4. `slot_front_top`（4 号：前顶槽，对应 `R` / `F`）
  5. `slot_front`（5 号：前槽，对应 `T` / `G`）
- 底层 `DeviceMgr.slots_device` 中的第 6 项是 **`device_slot_wheel`（左侧仪表盘的车轮槽）**，并非武器栏槽位。
- 本 Mod 自动过滤车轮槽，并将 `Q W E R T` 与 `A S D F G` **严格绑定在车体固定 1~5 号武器槽位**上——即使中间某个槽位空置，后续槽位的按键也绝不发生偏移。

## 2. 工具箱各升级阶段（Stage-Aware）完整机制

Mod 直接读取游戏内 `ToolBoxMgr` 的工具等级与升级属性，无需打开右下角工具箱，也无需用鼠标拖拽：

| 快捷键 | 工具进化路线 | 各阶段自动适配行为 |
| :--- | :--- | :--- |
| **`Space`** | **全局智能抢修** | 按紧急优先级自动处理：唤醒昏迷角色 → 灭火 → 除酸 → 擦水/吹干 → 割表层藤蔓 → 踹醒沉睡设备 → 扳手修 0 血设备 → 车载维修包回血 |
| **`A~G`** | **1~5 号槽定点抢修** | 对正上方 `Q~T` 对应的固定槽位执行：除酸 → 灭火 → 割藤 → 擦水/吹干 → 踹醒 → 扳手/维修包修血 |
| **`Z`** | **单向扳手 → 棘轮扳手 → 自动扳手 + 车载维修包** | 有 0 血损毁设备时按当前扳手阶段倍率抢修；无 0 血设备时自动触发**车载维修包（`Widget_Fix_Context`）**为受损设备或车体回血 |
| **`X`** | **灭火器（各阶段）** | 按当前灭火器等级速率扑灭着火设备 |
| **`C`** | **手锯 (`Lv0`) → 剪刀 (`Lv1`) → 电锯 (`Lv2`) → 圆锯 (`Lv3`)** | 自动识别藤蔓层级（`upper_vines.Count == 0`），永远从最外层藤蔓开始切除（**零顺序错误扣血惩罚**），切割速度随阶段倍增 |
| **`V`** | **抹布 (`Lv0`) → 大抹布 (`Lv1`) → 拖把 (`Lv2`) → 吹风筒 (`Lv3`)** | **前期（抹布/大抹布/拖把）**：免瞄准自动擦除单台设备上的水滴与强酸；<br>**后期（吹风筒 `Drier` `Lv3`）**：按下 `V` 直接触发**全车所有设备同步吹干**！ |
| **`B`** | **充气锤 (`Lv0`) → 惨叫鸡 (`Lv1`) → 闹钟 (`Lv2`) → 除颤仪 AED (`Lv3`)** | **前期**：每次敲醒 1 名昏迷角色（支持 `B + 1~6` 指定唤醒）；<br>**后期（除颤仪 `AED` `Lv3`）**：按下 `B` 直接**全车所有昏迷角色同步电击唤醒**！ |

## 4. 自动托管（`[AUTO]`）与手动无缝接管机制

- **开启/关闭方式**：
  - 按 **`Tab`**：一键开启或关闭全车所有武器槽的 `[AUTO]` 自动托管。
  - 按 **`Ctrl + Q~T`**：单独切换对应槽位的 `[AUTO]` 自动托管。
  - **鼠标点击取消**：开启托管后，直接用鼠标左键点击**屏幕顶部绿色横幅**或**槽位下方的 `[🟢自动]` 标签**即可立即取消。
- **随时手动接管**：
  - 在自动托管开启期间，您仍然可以随时按 `Q~T`、`Shift + Q~T`、`Alt + Q~T` 触发手动动作。
  - 当您用鼠标点击或拖拽某个武器面板时，该槽位的后台托管会自动礼让暂停，绝不干扰鼠标拖拽。

## 5. 自定义键位配置与开发者编译说明

- **修改键位（`OneWayTickets.KeyboardMod.ini`）**：
  - 安装后在游戏根目录生成 `OneWayTickets.KeyboardMod.ini`，可用记事本修改任意按键或修理速率倍率。
  - 游戏中按 **`F10`** 即可热重载配置（无需重启游戏），按 **`F9`** 可显示/隐藏界面提示。
- **从源码重新编译（仅开发者需要）**：
  - 普通玩家直接双击根目录的 `双击安装Mod (Install).bat` 即可使用 `dist/` 下预编译好的组件完成安装，无需安装任何开发工具。
  - 开发者若修改了 `src/` 下的 C# 源码，可执行：
    ```powershell
    powershell -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -BuildFromSource
    ```
