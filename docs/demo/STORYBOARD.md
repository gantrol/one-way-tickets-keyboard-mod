# 键盘 Mod · 28 秒演示分镜

当前是**键盘动效分镜预览，尚未加入真实游戏录屏**，用于确认节奏、按键提示与字幕。

[打开动态预览](./preview.html) · [查看视频草案](./keyboard-demo-preview.mp4) · [字幕文件](./subtitles.srt)

预览导出：1280 × 720、30fps、无配音。正式成片建议：1920 × 1080、30fps、无配音；游戏画面为主体，键盘图仅作按键提示。

| 时间 | 按键与屏幕字幕 | 正式成片画面 |
| --- | --- | --- |
| 0–2 秒 | 《再再启程》键盘 Mod | 标题与键盘图定格。当前预览标注“分镜预览”。 |
| 2–7 秒 | Caps Lock · 全武器托管 | 按下 Caps Lock，显示 `[AUTO]`，保留实际开火、装填过程。 |
| 7–12 秒 | 按住 Space · 自动拎工具抢修 | 工具自动取出，处理一处能清楚看见的故障。 |
| 12–17 秒 | Shift + A · 持续装填 | 1 号槽放加特林，按住 Shift+A，展示装填。小字：具体动作随设备变化。 |
| 17–22 秒 | Alt + A · 持续搬弹 | 同一槽位加特林，按住 Alt+A，展示搬弹。小字：具体动作随设备变化。 |
| 22–25 秒 | Alt + Y · 与替补轮换 | 展示 1 号角色与替补角色轮换。 |
| 25–28 秒 | 键位与安装方法见 README | 三张键位图缩略图与简短片尾。 |

## 待录素材

1. 托管：Caps Lock 开关、`[AUTO]` 状态与一段攻击/装填。
2. 抢修：按住 Space，完整处理一处明显故障。
3. 装填：1 号槽加特林，按住 Shift+A。
4. 搬弹：同一槽位加特林，按住 Alt+A。
5. 轮换：按住 Alt、点按 Y，展示对应角色与替补的变化。

录屏保持游戏 HUD 可见；手动武器段先关闭托管、取消角色选择，避免输入被派驻操作消耗。开始下一镜前松开修饰键。每镜额外保留前后约 1 秒，便于剪辑。

键盘与字幕沿用 SVG 的暖白、低饱和配色；每段只强调当前按键，文字放在固定位置。用短淡入淡出衔接，保留动作发生所需时间。游戏素材补齐后，用实录替换当前动效示意。
