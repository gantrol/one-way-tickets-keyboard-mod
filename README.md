# 《再再启程 One Way Tickets》全键盘与减负 Mod

**[English (README_EN.md)](./README_EN.md)** | **[详细机制与全武器表 (docs/DESIGN.md)](./docs/DESIGN.md)**

保留原版鼠标操作，用**左手四排键盘**搞定选人派驻、5 槽武器操控/自动托管、以及免拖拽一键抢修。

---

## 一键安装 / 卸载（无需命令行）

1. 先**关闭游戏**。
2. 双击文件夹内的 **`双击安装Mod (Install).bat`** 即可自动识别 Steam 游戏目录并完成安装（若安装在非标准位置会自动弹出文件夹选择框）。
3. 如需还原原版，双击 **`双击卸载Mod (Uninstall).bat`** 即可。

### 常用组合键速查

- **武器进阶（`Q ~ T`）**：
  - **直接按 `Q ~ T`**：武器主动作（挥砍 / 射击 / 空仓自动装填）
  - **`Ctrl + Q ~ T`**（或 **`Tab`** 全开）：切换 **`[AUTO]` 自动托管**（开启后随时可手动按键或鼠标接管，点击顶部横幅或槽位绿标即可取消）
  - **`Shift + Q ~ T` / `Alt + Q ~ T`**：武器副操作 2 / 副操作 3（磨刀、提前上膛、远程投矛、校准等，详见 [docs/DESIGN.md](./docs/DESIGN.md)）
- **人物调配（`1 ~ 6`）**：
  - **`1 ~ 6` → `Q ~ T`**：派驻角色到对应槽位（再按切换主/副工位）
  - **双击 `1 ~ 6`**（或按 `0` / `Backspace`）：撤回角色休息
- **界面与改键**：
  - **`F9`**：显示 / 隐藏屏幕按键提示（营地与结算界面会自动隐藏）
  - **`F10`**：热重载游戏根目录下的 `OneWayTickets.KeyboardMod.ini` 自定义键位配置
