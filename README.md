# 《再再启程 One Way Tickets》全键盘与减负辅助 Mod (`OneWayTickets.KeyboardMod`)

**[English Documentation (README_EN.md)](./README_EN.md)**

专为 **《再再启程》(One Way Tickets)** 设计的无损键盘操控与减负 Mod。在不影响原版鼠标操作的前提下，引入 **左手四排空间映射矩阵（人物 / 武器 / 槽位抢修 / 工具箱）**、**武器 1~3 键分级动作与智能闭环**、以及 **一键全局抢修/自动托管系统**，彻底解决工具箱拖拽繁琐与多武器手忙脚乱的问题。

---

## 核心特性

1. **工具箱免开箱、免拖拽（核心痛点解决，完整适配工具升级阶段）**
   - **按住 `Space`（空格）全局智能抢修**：自动按紧急优先级唤醒眩晕角色、扑灭火焰、中和强酸、擦干积水、割断藤蔓、踹醒沉睡设备，并为掉血最低的设备持续扳手维修。
   - **点按或按住 `A / S / D / F / G / H` 固定槽位抢修**：严格对应车体左起 **固定第 1~6 号槽位**（即使中间有空槽位，按键也绝不偏移！与正上方 `Q / W / E / R / T / Y` 纵向一一对齐）。
   - **点按或按住 `Z / X / C / V / B` 定向工具（自动适配各阶段工具特性）**：
     - `Z`（扳手/车载维修包）：适配基础扳手、双向棘轮、自动旋转扳手阶段速率；无 0 血损毁设备时自动调用车载维修包恢复受损设备或车体耐久。
     - `X`（灭火器）：读取当前灭火器阶段效率持续扑灭全车火情。
     - `C`（手锯 -> 剪刀 -> 电锯 -> 圆锯）：严格优先切除最表层藤蔓（`upper_vines.Count == 0` 零自伤）并对藤蔓怪本体造成真实伤害，随工具阶段提升切割速率。
     - `V`（抹布 -> 大抹布 -> 拖把 -> 吹风筒）：**前期抹布/大抹布/拖把**按单台设备逐滴精准擦拭水滴与酸液；升级到 **吹风筒（`Drier`）** 后，按 `V` 直接**全车所有设备同步吹干**！
     - `B`（充气锤 -> 惨叫鸡 -> 闹钟/喇叭 -> 除颤仪 AED）：前期唤醒工具单次唤醒 1 名昏迷角色（支持 `B + 1~6` 定向唤醒指定角色）；升级到 **除颤仪（`AED`）** 后按 `B` 直接**全车昏迷角色同步电击唤醒**！
   - **即时按键反馈**：每次按下武器键或工具箱快捷键，顶部中央状态栏会高亮显示**本次按下的按键、实际调用的阶段工具名称、以及作用的槽位与设备名称**（如 `⌨ [V:吹风筒(全车吹干)] 吹风筒生效：已同步吹干全车设备水滴/酸液！`），同时对应槽位角标呈现金色高亮脉冲反馈。

2. **武器栏全键盘操控（支持 1~3 种操作 + 自动托管期间随时手动接管）**
   - **主操作与智能闭环（点按/按住 `Q / W / E / R / T / Y`）**：
     - 点按或按住均可**立即触发武器主动作**（如近战挥砍/敲击、远程立刻开火/上膛、车轮加速、战鼓左槌等），同时运行智能闭环（弹药耗尽自动装填、大剑自动蓄力挥砍、炮台自动转向瞄准）。
   - **自动托管模式（`Ctrl + Q~Y` 单槽切换 / `Tab` 全槽一键开关）**：
     - 开启后后台自动循环开火与装填。
     - **随时手动接管**：在 `[AUTO]` 自动托管状态下，**随时可以按 `Q~Y` / `Shift+Q~Y` / `Alt+Q~Y` 或直接用鼠标拖拽武器面板进行手动操控**（鼠标操作面板时后台自动礼让，绝不抢夺焦点）。
     - **醒目取消提示与点击关闭**：开启托管时，屏幕顶部中央横幅与槽位绿色 `[🟢自动]` 标签均提供清晰的快捷键提示，且**支持直接用鼠标左键点击横幅或槽位标签一键关闭托管**。
   - **副操作 2（`Shift + Q~Y`）与副操作 3（`Alt + Q~Y`）**：
     - 完整覆盖拥有 2~3 种独立操作的特殊武器（详见下方对照表）。

3. **角色键盘选人与快速派驻（`1 ~ 6`）**
   - 点按 `1 ~ 6` 选中前排角色，随后按 `Q ~ Y` 即可将该角色派驻到对应设备工位（同一设备有攻击/装填/打磨双工位时，重复按 `Q ~ Y` 自动在工位间轮换）。
   - 双击 `1 ~ 6` 或按 `0` / `Backspace` 撤回角色休息；按 `Alt + 1 ~ 6` 与替补席轮换。

4. **自适应 HUD 提示条与热重载**
   - 仅在战斗/行进场景显示快捷键角标，**在营地（安全区）与结算界面自动隐藏**，绝不遮挡遗物栏与非战斗 UI。
   - 游戏中按 `F9` 随时显示/隐藏快捷键提示，按 `F10` 随时热重载 `OneWayTickets.KeyboardMod.ini` 键位配置。

## 安装与更新指南

### 1. 自动安装（推荐）

> **注意**：安装或更新前请先**关闭游戏**（否则 DLL 文件被游戏进程占用无法覆盖）。

在项目根目录下使用 PowerShell 运行安装脚本（脚本会**自动从注册表与 `libraryfolders.vdf` 扫描所有磁盘的 Steam 库**来定位《再再启程》目录，并将定位到的 `Managed` 路径传给编译器）：

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-Mod.ps1
```

如果您的游戏未通过 Steam 安装，也可以通过 `-GameRoot` 手动指定路径：

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -GameRoot "E:\SteamLibrary\steamapps\common\再再启程 One Way Tickets"
```

安装脚本会自动完成以下操作：
1. 编译 `Release` 版本的 `OneWayTickets.KeyboardMod.dll`；
2. 备份原版 `One Way Tickets_Data\Managed\World.dll` 为 `World.dll.bak`；
3. 将 `OneWayTickets.KeyboardMod.dll` 复制到 `Managed` 目录并完成入口注入；
4. 在游戏根目录生成默认配置文件 `OneWayTickets.KeyboardMod.ini`（若已存在则保留您的自定义配置）。

### 2. 卸载与还原原版

运行卸载脚本即可一键还原原版 `World.dll` 并清理 Mod 文件：

```powershell
powershell -ExecutionPolicy Bypass -File .\Uninstall-Mod.ps1
```

## 自定义键位配置 (`OneWayTickets.KeyboardMod.ini`)

安装后，游戏根目录下会生成 `OneWayTickets.KeyboardMod.ini`。您可以用记事本或任意文本编辑器打开修改键位或速率倍率：

- 修改后无需重启游戏，直接在游戏内按 **`F10`** 即可热重载生效！
- 按 **`F9`** 可在游戏内随时开启或关闭屏幕上的快捷键提示。
