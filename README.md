# 《再再启程 One Way Tickets》双手全键盘与减负 Mod

**[English (README_EN.md)](./README_EN.md)** | **[详细机制与全武器表 (docs/DESIGN.md)](./docs/DESIGN.md)**

保留原版鼠标操作，采用**双手主行（`ASDFG` + `HJKL;`）分工设计**：左手专注 **1~5 号武器、定点抢修、刹车与灵能加速**，右手专注 **工具箱拎出抢修、人物调配与一键最优自动分配**，按键反馈显示在右侧工具箱正上方。

---

## 一键安装 / 卸载（无需命令行）

1. 先**关闭游戏**。
2. 双击文件夹内的 **`双击安装Mod (Install).bat`** 即可自动识别 Steam 游戏目录并完成安装（若安装在非标准位置会自动弹出文件夹选择框）。
3. 如需还原原版，双击 **`双击卸载Mod (Uninstall).bat`** 即可。

### 常用操作速查

- **左手主行：1~5 号武器（`A S D F G`）**
  - **点按 / 按住 `A ~ G`**：武器主动作（挥砍 / 射击 / 空仓自动装填）
  - **`Ctrl + A ~ G`**（或 **`Tab`** 全开）：切换 **`[AUTO]` 自动托管**（随时可手动按键或鼠标接管，点击工具箱上方状态栏或槽位绿标即可取消）
  - **`Shift + A ~ G` / `Alt + A ~ G`**：武器副操作 2 / 副操作 3（磨刀、提前上膛、远程投矛、校准等，详见 [docs/DESIGN.md](./docs/DESIGN.md)）
- **左手上排 & 下排：定点抢修（`Q ~ T`）与行车控制（`Z X C`）**
  - **`Q W E R T`**：定点抢修下方对应的 1~5 号槽位（自动拎出工具除障 + 修血）
  - **`Z`（按住）**：拉起刹车拉杆减速/停车，松开恢复行进
  - **`X`（点按/按住）**：触发**灵能加速冲刺** + 鼓动熔炉风箱加速 + 推车启动
  - **`C`**：车轮槽保留键（喷气车轮加速 / 推车）
- **右手主行 & 上排：工具箱（`H J K L ;`）与人物调配（`Y U I O P [` + `'`/`]`）**
  - **`H J K L ;`**：分别从工具箱拎出 **扳手 / 灭火器 / 锯子 / 抹布(吹风机) / 唤醒工具** 执行抢修并自动放回工具箱（随工具升级自动进阶）
  - **`'` 或 `]`**：**人物一键自动分配**（按各角色能力矩阵自动派驻最佳空闲槽位；**`Ctrl + '` / `Ctrl + ]`** 开启持续自动调配，弹尽时自动换位装填）
  - **`Y U I O P [`**（兼容 `1 ~ 6`）：选中 1~6 号角色后按 `A ~ G`（或 `Q ~ T`）派驻；双击角色键或按 `Backspace` 撤回休息
- **界面与改键**：**`F9`** 显隐提示，**`F10`** 热重载游戏目录下的 `OneWayTickets.KeyboardMod.ini`
